# 16 — Glosarium Singkat

| Istilah | Penjelasan sederhana |
|---|---|
| **Data Wisuda** | Excel daftar calon/lulusan yang perlu dilengkapi sertifikasinya |
| **SITASI** | Sumber data riwayat sertifikasi mahasiswa yang disediakan ITCC |
| **Certiport** | Sumber data hasil ujian sertifikasi yang digunakan sebagai pembanding |
| **NIM** | Nomor Induk Mahasiswa, identitas utama untuk join Wisuda↔SITASI |
| **MOS** | Microsoft Office Specialist; kelompok sertifikasi pada data |
| **MCF** | Microsoft Certified Fundamentals; kelompok sertifikasi pada data |
| **MTCNA** | Kategori sertifikasi lain yang terdapat di SITASI; di luar output utama MVP |
| **Data master** | Data sumber SITASI/Certiport yang diimpor dan diperbarui secara berkala |
| **Batch/import_id** | Sekelompok baris yang berasal dari satu proses upload |
| **Active batch** | Versi data sumber yang digunakan untuk proses sinkronisasi baru |
| **Sync session** | Satu proses unggah + sinkronisasi daftar wisuda |
| **Source row** | Nomor baris di Excel sumber untuk mempermudah audit |
| **Normalisasi** | Merapikan representasi teks untuk dibandingkan tanpa menghapus asli |
| **Exact match** | Kesamaan persis sesudah normalisasi yang disepakati |
| **Fuzzy matching** | Mengukur kemiripan teks; dipakai untuk saran kandidat, bukan putusan otomatis |
| **Attempt** | Satu catatan percobaan/hasil ujian; satu orang dapat memiliki banyak attempt |
| **Validation status** | Hasil pencocokan/validasi bukti per mahasiswa atau per ujian |
| **Manual review** | Pemeriksaan manusia atas kasus ambigu/konflik |
| **Audit trail** | Catatan siapa melakukan apa, kapan, dan mengapa |
| **PRD** | Dokumen kebutuhan produk: tujuan, pengguna, fitur dan kriteria diterima |
| **SRS** | Spesifikasi persyaratan software yang dapat diuji |
| **ERD** | Diagram hubungan antar tabel database |
| **API** | Antarmuka komunikasi Next.js ke FastAPI |
| **RLS** | Row Level Security; kebijakan akses baris pada PostgreSQL/Supabase |
| **MVP** | Versi minimal yang menyelesaikan fungsi utama dan dapat diuji |
| **UAT** | User Acceptance Test: pengujian oleh calon pengguna/petugas |
